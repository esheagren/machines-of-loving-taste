# Working on Machines of Loving Taste

The owner can edit essay drafts at `/edit`. When asked to read or incorporate those edits, read `docs/essay-editor.md` and run `npm run drafts` to retrieve the latest shared text and before/after comparisons. Drafts are private and are not automatically published. Keep credentials and the retrieved draft files out of Git.

The site is generated by `src/site.js`. After site changes, run `node src/site.js`, copy `report/site.html` to `public/index.html`, and run `npm test`. Commit the generated site and editor outputs with their source changes.
